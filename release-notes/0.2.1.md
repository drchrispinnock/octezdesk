# OctezDesk 0.2.1

- **Fixed:** after OctezDesk was uninstalled, or its background helper was stopped abruptly, a hidden `wsl.exe` process could be left behind. It kept the Linux environment running and stopped Setup from reinstalling OctezDesk ("Failed to remove existing application directory"). That process now always ends with the helper.

If OctezDesk 0.2.0 is installed, it updates to this version by itself.
