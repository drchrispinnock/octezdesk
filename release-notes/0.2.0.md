# OctezDesk 0.2.0

The first packaged release of OctezDesk for Windows.

- **Installer.** Run `OctezDesk.Win-win-Setup.exe`. It installs for your Windows user only, so it needs no administrator rights, and adds shortcuts to the Start menu and the desktop.
- **Automatic updates.** OctezDesk checks for new versions when the main screen opens and every six hours, and downloads them in the background. Choose **Restart now**, or the update installs when you close OctezDesk. ☰ → **Check for OctezDesk updates** checks straight away. Your node keeps running during an update.
- **Uninstalling** removes the app only. Your node, its data and your keys stay in the `OctezDesk` WSL distro. To delete those too, run `wsl --unregister OctezDesk`, but first make sure you no longer need the keys in it.

The installer isn't code-signed yet, so Windows SmartScreen may warn about an unknown publisher. Choose **More info**, then **Run anyway**.

Also in this release: the setup wizard with node, baker, testnet funding and DAL node screens; health and logs for the node, baker and DAL node; and prerequisite checks for Windows, virtualisation and WSL.
