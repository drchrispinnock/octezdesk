# OctezDesk 0.2.4

- **Start, stop and restart each service.** The ☰ menu now has **Start**, **Stop** and **Restart**, each for the node, the DAL node and the baker.
- **Deconfigure and stop** turns off the DAL node or the baker for good, until you set it up again. Its data and the baking keys are kept. Turning off the DAL node also makes the baker bake without it.
- **Set up the baker or the DAL node on its own.** ☰ → **Set up baker…** and **Set up DAL node…** go straight to that screen, without the node settings. Once set up, they're called **Baker settings…** and **DAL node settings…**.
- **Bake with keys on a remote signer.** On the Baker screen, choose **Use keys on a remote signer**, enter its address (TCP, HTTP or HTTPS; ports 7732, 6732 and 443 by default) and choose **List keys**. Then pick the consensus key and, optionally, a tz4 companion key. If the signer won't list its keys, type the addresses. No secret key is stored on this PC, and this option is available on mainnet.
- **Safer with existing WSL distros.** If you already have a WSL distro called `OctezDesk` that OctezDesk didn't make, OctezDesk leaves it alone and uses `OctezDesk-2` instead.

If an earlier 0.2 version is installed, OctezDesk updates to this one by itself.
