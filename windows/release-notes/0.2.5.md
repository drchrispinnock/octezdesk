# OctezDesk 0.2.5

- **Fixed: updates could fail, and OctezDesk then closed as soon as it opened.** The dashboard's log tabs kept running in the background after its window closed, and they stopped the update from replacing OctezDesk's files. OctezDesk tried again each time it started and closed without showing its window. The log tabs now stop when the window closes, and nothing OctezDesk starts can block an update any more.

If OctezDesk keeps closing as soon as you open it, restart Windows, then open it again so the update installs. Coming from 0.2.3 this can happen once more on the way from 0.2.4 to this version; restart again. From this version on, updates don't need it.
