# OctezDesk 0.2.5

- **Fixed: OctezDesk 0.2.4 wouldn't open on PCs with Smart App Control.** Windows blocked it because it wasn't signed. OctezDesk is now signed with a code-signing certificate ("Open Source Developer Chris Pinnock"). Windows now shows that name as the publisher.
- **Fixed: updates could fail, and OctezDesk then closed as soon as it opened.** The dashboard's log tabs kept running in the background after its window closed, and they stopped the update from replacing OctezDesk's files. The log tabs now stop when the window closes, and nothing OctezDesk starts can block an update any more.

**If 0.2.4 doesn't open, it can't update itself:** download `OctezDesk.Win-win-Setup.exe` from this release and run it. It installs over the old version. Your node, its data and your keys are kept. If 0.2.3 keeps closing as soon as you open it, restart Windows, then open it again.
